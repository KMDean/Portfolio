Wireshark Log Dissector in TSHARK

Automated Network Traffic Analysis:

Developed a custom diagnostic utility using TShark and Batch scripting to automate the extraction and analysis of telemetry from Wireshark packet captures. I engineered the script to parse large-scale datasets, isolating mission-critical conversation statistics and flow dynamics to identify network behavior patterns.

Packet Filtering & Data Synthesis:

Designed and implemented complex filtering logic to calculate frame distributions across specific protocols and network layers. By leveraging the TShark command-line interface, I automated the isolation of high-priority traffic, enabling rapid identification of anomalies or bottlenecks within the captured data.

Command-Line Interface (CLI) Architecture:

Architected a terminal-based reporting system that synthesized raw packet data into structured, human-readable tables. This custom-built interface streamlined the review process for network administrators, transforming low-level hexadecimal and binary streams into actionable flow statistics and performance metrics.
