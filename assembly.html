Grade Calculator in Assembly

Embedded Systems Engineering (Assembly):

Developed a performance-validation system on a Wytec Dragon12-Plus board using 68HC12 Assembly to determine student pass/fail status based on multi-variable grading criteria. I engineered a modular codebase utilizing Index Registers X and Y alongside Accumulators A and B for efficient memory addressing and data manipulation, resulting in a low-level firmware solution that interfaced directly with hardware parallel ports to output real-time results.

Algorithmic Logic & Hardware Interfacing:

Implemented a multi-stage logic gate to evaluate weighted grading tiers, requiring a minimum 50% threshold across both "Practical" and "Theory" datasets. I designed and integrated custom subroutines—including Calculate_Average for arithmetic processing and Pass_Fail for conditional branching—while configuring the board’s 7-segment Hex Displays through specialized hardware initialization and delay-timing loops to ensure human-readable output.

Memory Mapping & Execution Flow:

Architected the main execution loop, Pass_Fail_Calc, utilizing structured data blocks (db) to manage student records and nested loops for iterative grade processing. By leveraging hardware-level registers for bitwise operations and port configurations, I streamlined the transition from raw data input to physical hardware display, ensuring high-integrity execution within a resource-constrained embedded environment.
