QNX Embedded Systems Server / Client

Real-Time Embedded Systems Engineering:

Architected a distributed access control system within the Blackberry QNX environment using C, leveraging the QNX Namespace to establish secure client-server communication. I engineered a three-tiered architecture consisting of an input client, a display server, and a central controller to manage asynchronous hardware-status messaging.

Finite State Machine (FSM) Logic:

Implemented a robust Deterministic Finite Automaton (DFA) to govern the operational lifecycle of a secure entry system (Lock/Unlock/Open/Close). By applying compiler theory and state-transition logic, I ensured the system maintained high-integrity operational order, programmatically preventing invalid sequences such as unauthorized opening of locked nodes.

Distributed Inter-Process Communication (IPC):

Designed a complex Client-Server-Client workflow to facilitate real-time synchronization between user input and hardware-prompt displays. This architecture utilized specialized QNX system calls for server creation and naming, ensuring reliable and secure data flow across the embedded network infrastructure.
