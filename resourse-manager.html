QNX Metronome Resource Manager

RTOS Resource Management:

Engineered a custom QNX Resource Manager in C to facilitate real-time timing and synchronization. I extended the QNX file system namespace to create a specialized device interface, allowing the system to process high-priority metronome pulses and timing signatures with microsecond precision.

Concurrent Architecture & Synchronization:

Implemented a Thread Pool architecture to handle asynchronous command-line inputs and terminal interrupts. By utilizing QNX Pulses for non-blocking inter-process communication, I ensured that system commands—including start, stop, pause, and set—remained responsive without drifting from the real-time clock.

Multi-Threaded Logic & Control:

Developed a robust command-processing engine capable of interpreting complex temporal parameters and beats-per-measure configurations. I optimized the execution flow to maintain strict deterministic behavior, ensuring the embedded system provided stable, real-time feedback across a variety of user-defined time signatures.
