Machine Learning Breast Cancer Detection Web App

Medical Image Data Engineering:

Engineered a specialized Python pipeline to preprocess high-resolution ultrasound datasets for normal, benign, and malignant classifications. I developed a custom script to perform spatial mapping on binary masks, translating complex morphological shapes into normalized four-corner CSV annotations to facilitate high-precision training in TensorFlow.

Deep Learning Model Development:

Architected and trained a Convolutional Neural Number (CNN) model utilizing the Datature ecosystem and Kaggle oncology datasets. I optimized the training workflow by implementing automated annotation methods and refining model parameters to ensure accurate detection of nodules within diverse ultrasound imagery.

Full-Stack Deployment & Interface Design:

Transformed a command-line prediction script into a user-centric web application to streamline the diagnostic interface. By integrating the TensorFlow backend with a responsive web frontend, I enabled real-time image uploads and automated classification, bridging the gap between complex ML outputs and accessible clinical tools.
