PLATYPUS Compiler in C

Compiler Architecture & Memory Management:

Engineered a multi-stage compiler for the PLATYPUS language in C, architecting a high-performance Buffer module to manage input streams. I implemented low-level memory allocation and character-handling logic to ensure the efficient and secure transition of source code into the processing pipeline.

Lexical & Syntactic Analysis:

Developed a comprehensive Scanner and Parser based on strict language specifications and formal grammar rules. I designed the scanner to perform lexical analysis for token identification and built the parser to validate complex syntactic structures, ensuring that the source code adhered to the language's defined operational logic.

Formal Grammar & Logic Engineering:

Deeply analyzed the PLATYPUS grammar to implement recursive-descent parsing and error-handling protocols. By mastering the language’s unique specifications, I translated high-level abstract logic into a structured system capable of detecting syntax anomalies and preparing code for downstream execution.
